RotoGrinders projections

RotoGrinders has no export. The optimizer can read the projections page itself using your login (automatic), or you can grab the table from your browser with one click (backup).

Automatic: your RotoGrinders login (one-time setup)

The optimizer signs in to RotoGrinders itself and reads the projections table. No cookie to copy, and nothing to redo every week.

  1. Change your RotoGrinders password to one you use nowhere else.
  2. Vercel → dfs-optimizer → Settings → Environment Variables → add RG_USER (your RotoGrinders username) and RG_PASS, each ticked Sensitive, Production and Preview → Save → redeploy production.
  3. Add NTFY_TOPIC the same way: a long random string you invent. Install the ntfy app on your phone and subscribe to that exact string — it is how the pre-lock alert reaches you, and the topic name is its only secret.

The session is cached, so sign-ins happen roughly weekly rather than on every run. If the password is wrong, sign-in is attempted at most 3 times per 30 minutes rather than every five minutes, so a bad password cannot hammer your account — builds will say so, and the button below still works meanwhile. RG_COOKIE is still honored and overrides the stored session if you ever need to paste one by hand.

Automated reading of your own account may go against RotoGrinders' terms of service; that choice is yours.

Using the grabber, when the login is broken

Normally you do none of this: the 1pm build reads RotoGrinders itself. Use these steps only if a build says the sign-in failed.

  1. Open RotoGrinders → NBA → Projected Stats, DraftKings, logged in. Let the table load fully.
  2. Click Grab RG projections in your bookmarks bar. It downloads rg-projections-DATE.tsv, copies the same text to your clipboard, and tells you how many players it captured.
  3. Back in the optimizer, choose that file in the RotoGrinders box, or paste into the paste box, and Build.

The optimizer checks the columns against the page's headers (FPTS must be column 28, not the PrizePicks column next to it) and refuses the file if anything doesn't line up, so a layout change can never silently feed it wrong numbers.

On a phone, or if dragging doesn't work

  1. Bookmark any page, then edit that bookmark.
  2. Replace its address with the text below (Copy button) and name it Grab RG projections.
  3. On the RotoGrinders page, open your bookmarks and tap it.
